# workman-base16

Base16 colour scheme parsing and [egui](https://github.com/emilk/egui) theming, split out of
the [workman](https://github.com/durbanlegend/workman) markdown viewer.

Reads Base16 / tinted-theming scheme files (old `scheme:` layout and new `palette:` layout)
without a YAML library, and converts them to egui `Visuals`.
